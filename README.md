# 
## Описание проекта

Разведочный анализ данных об автомобилях
для дальнейшего рпогнозирования их стоимости

Тип задачи: регрессиия.

Целевая переменная: selling_price.

##Запуск проекта

Инструкция по клонированию репозитория,
созданию виртуального окружения,
установке библиотек и запуску ноутбука.

##Описание модулей

eda/eda.ipynb - исследование данных,
очистка, визуализация и выводы
