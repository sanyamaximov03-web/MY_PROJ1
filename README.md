# Car Price Prediction — разведочный анализ данных

Лабораторная работа № 1. Исследование набора данных о подержанных автомобилях для дальнейшего прогнозирования цены продажи.

## Описание проекта

**Тип задачи:** регрессия. **Целевая переменная:** `selling_price` — цена автомобиля в индийских рупиях (INR).

В работе выполняется разведочный анализ данных (EDA): изучение таблицы, поиск и удаление дубликатов, обработка пропусков и некорректных значений, исследование взаимосвязей признаков и подготовка очищенного датасета для последующих лабораторных работ. **Обучение модели в этой работе не выполняется.**

Используются **строго восемь исходных столбцов**, без создания новых признаков:

| Столбец | Значение | Роль |
| --- | --- | --- |
| `name` | Название автомобиля | Категориальный признак |
| `year` | Год выпуска | Числовой признак |
| `selling_price` | Цена продажи, INR | **Целевая переменная** |
| `km_driven` | Пробег, км | Числовой признак |
| `fuel` | Тип топлива | Категориальный признак |
| `seller_type` | Тип продавца | Категориальный признак |
| `transmission` | Тип трансмиссии | Категориальный признак |
| `owner` | Категория предыдущих владельцев | Категориальный признак |

**Источник данных:** [Vehicle Dataset from CarDekho (Kaggle)](https://www.kaggle.com/datasets/nehalbirla/vehicle-dataset-from-cardekho).

## Запуск проекта

Нужны **Linux**, **Python 3.10 или новее**, **Git** и **VS Code** с расширениями **Python** и **Jupyter**.

### 1. Получить файлы проекта

```bash
git clone https://github.com/sanyamaximov03-web/MY_PROJ1.git
cd MY_PROJ1
```

Подставьте настоящий адрес репозитория GitHub. Если проект уже есть локально, повторно клонировать его не нужно — достаточно открыть существующую папку в VS Code.

### 2. Создать и активировать виртуальное окружение

```bash
python3 -m venv .venv_my_proj
source .venv_my_proj/bin/activate
```

### 3. Установить зависимости

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Основные библиотеки: `pandas`, `matplotlib`, `seaborn`, `plotly`, `ipykernel`, `nbformat`. Если в анализе применяется метод Спирмена, дополнительно потребуется `scipy`; в текущих пяти графиках используется корреляция Пирсона.

### 4. Добавить исходный датасет

Создайте папку `data/`, если её нет (`mkdir -p data`), скачайте CSV из источника и поместите его в `data/dataset.csv`. Исходный CSV не включён в репозиторий GitHub.

### 5. Выполнить анализ

Откройте папку проекта в VS Code, затем `eda/eda.ipynb`. В меню **Select Kernel** выберите Python из `.venv_my_proj`, после чего нажмите **Restart Kernel → Run All**.

## Лабораторная работа №2 — исследование моделей

Использована очищенная таблица `data/clean_dataset.pkl` из ЛР1. Входные
признаки: `year, km_driven, name, fuel, seller_type, transmission, owner`. Цель: `selling_price`.

- Обучающая/тестовая выборки: 75% / 25%, `random_state=42`.
- Модель: `RandomForestRegressor`.
- Числовые признаки: `StandardScaler`.
- Категориальные признаки: `OrdinalEncoder`.
- Инженерия признаков: `PolynomialFeatures(degree=2)`.
- Отбор 5 из 10 полученных признаков: `SequentialFeatureSelector`.
- Подбор гиперпараметров: `GridSearchCV`, 8 комбинаций, 3 фолда, оптимизация MAE.
